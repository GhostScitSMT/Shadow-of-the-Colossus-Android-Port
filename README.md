# Shadow-of-the-Colossus-Android-Port
An experimental Android build designed for handheld play, with controller support, touch controls, and configurable button icons. Tested on the AYN Thor.
Features
- Touch controls: Two virtual sticks, directional pad, face buttons, shoulder buttons, Start/Select, and stick clicks.
- Multi-touch support: Move, adjust the camera, and hold multiple buttons together.
- Optional overlay: Hide touch controls when using a controller and adjust their opacity.
- Switchable icons: Choose original PlayStation symbols or modded Y/X/A/B labels for both the touch overlay and supported in-game prompts.
- Control options: Classic, responsive, and modern layouts, plus stick dead-zone and camera-sensitivity settings.
- Display options: Original resolution, 720p, and 1080p settings, widescreen, and screen-fill options.
- Accessible menu: A top-center Menu button provides access to cheats and returning to the launcher.
- USA cheat support: A curated cheat list with individual toggles.
Getting Started
1. Install the Handheld Edition APK.
2. Import your own compatible USA PS2 ISO — SCUS-97472.
3. Choose your controls, icons, and display settings.
4. Press Play.
Touch controls work without physical-controller calibration. Icon changes apply when launching the game again.
Save Compatibility
The touch preview installs alongside the earlier Shadow Android Preview. Existing saves can be copied into the new edition; afterward, each app maintains its own progress.
